Who makes it

Plyleaf is made by one independent developer at Yurgon, who builds small, useful apps. It is not a company product with a paid plan hidden behind the free one, and it is not a funnel into one.

It started with a simple annoyance: to print a booklet, scale a poster or put a book on an e-reader, most sites want you to upload your file to their server, register, or wait out a daily limit. None of that is needed. A modern browser can do the work itself.

Why it is free

The tools run in your browser, so there are no servers that process files and no bill that grows with every visitor. Serving a set of pages costs very little, which is why there is no account, no daily limit, no watermark and no advertising.

What every page tries to do

Each tool page explains the task, not just the button: what the settings mean, how to print the result, and what to do when something goes wrong. If a page left you guessing, tell us and it will be fixed.

Built on open source

Plyleaf is built on BentoPDF, an open-source PDF toolkit, and adds its own page design, explanations and tools such as the booklet maker. The full source code is public under the AGPL-3.0 licence: read it on GitHub.

How to check that files stay on your device

Open a tool, choose a file and watch the network panel of your browser’s developer tools while it works: the program code loads, your file is never sent. Some tools fetch their processing module the first time you use them, so the very first run needs a connection; your document still stays on your device. The privacy page explains what the site does count.
