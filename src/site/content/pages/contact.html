Where to write

Email hello@yurgon.app. A person reads every message, usually within a few days.

Report a problem

Tell us which tool you used, what you expected and what happened instead. The browser and device help too, for example “Safari on iPhone”.

Please do not attach a private document. Describe it instead (number of pages, which program made it) or send a sample with nothing confidential in it.

Suggest a tool

Missing something you do with PDFs every week? Write what you start with and what you need to end up with. Most of the tools on this site began as a request like that.
