How to password protect a PDF

  1. Add your PDF

    One file. It stays on your device.

  2. Set the passwords

    The user password is needed to open the file. Add an owner password if you also want to block printing, copying and editing.

  3. Encrypt and save

    Press Encrypt PDF. The protected PDF downloads.

What you get

To password protect a PDF is to encrypt it, so it cannot be read without the password. It is the right step before you email a contract, ID scan, medical record or bank statement. This tool encrypts in your browser, so the document and the password are never uploaded anywhere.

Set a password to open the PDF

The user password is required. Anyone who wants to open the file must type it. The PDF is encrypted with 256-bit AES, the strongest standard encryption in PDF, so the protection depends on how strong your password is. Use a long one that is not a word.

Add an owner password for restrictions

The owner password is optional. When you set one that differs from the user password, the file also gets usage restrictions: someone who opens it with only the user password cannot print, copy, edit, annotate, fill forms or rearrange pages. Leave it empty for no restrictions.

Restrict printing without a password to open

This tool always asks for a password to open the file. To block printing or copying while leaving the PDF openable by anyone, use Change Permissions.

If you forget the password

There is no recovery. AES-256 cannot be broken in any practical time, and nothing is kept anywhere but on your device. Write the password down in a safe place and keep an unprotected original for yourself.

How it works

A PDF encryption library (QPDF, compiled for the browser) applies AES-256 encryption on your device and saves a new file. The document and the passwords never leave your browser.

What people use it for, and when it will not work

Contracts, tax returns, payslips, ID and passport scans, medical and legal records, anything you send by email or keep in cloud storage.

  • Send the password separately, by message or phone, not in the same email as the file.
  • To remove it later, open the file in Unlock PDF with the password.
  • Restrictions are weaker than a password to open. Treat printing and copying limits as a polite request, not as security.

Questions and answers

How do I password protect a PDF?
Add the file, type a user password, press Encrypt PDF and save the protected copy.
Is it free to password protect a PDF?
Yes, with no account, no watermark and no limit on files.
What encryption does it use?
256-bit AES. There is no weaker option, so the strength comes down to your password.
What is the difference between the user and owner password?
The user password opens the file. The owner password, if different, also blocks printing, copying and editing.
Can I block printing without asking for a password to open?
Not with this tool. Use Change Permissions for that.
What if I forget the password?
It cannot be recovered. Keep the password safe and keep an unprotected original.
How do I remove the password later?
Open the file in Unlock PDF, type the password and save a copy without encryption.
Is it safe to protect a PDF online?
Here the file and the password stay in your browser and are never uploaded.
