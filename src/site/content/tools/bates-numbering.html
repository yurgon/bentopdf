How to add Bates numbers to a PDF

  1. Add your PDFs

    One or many, in the order they should be numbered.

  2. Set the style

    Pick a preset or write a custom template, then choose the padding, position, font and starting number.

  3. Apply and save

    Press Apply Bates Numbers. The numbered files download.

What you get

Template placeholders
Placeholder Prints Example
[BATES] The sequential number 000001, 000002
[PAGE] The page number within the file 1, 2, 3
[FILE] The file counter 1, 2
[FILENAME] The source file name contract

Bates numbering gives every page in a set of documents its own sequential identifier, so lawyers and reviewers can cite a page without confusion. It is standard in discovery, audits and records requests. Here you stamp the numbers in your browser, so privileged documents are never uploaded.

Prefixes, padding and custom templates

By default a Bates number is a six-digit zero-padded number such as 000001 at the footer center. Presets add an exhibit number, a case label and a page number, for example Exhibit 1 Case XYZ 000001 Page 1, and a preview shows the exact text before you process anything. For your own prefix, choose Custom style and write a template: SMITH-[BATES] gives SMITH-000001, SMITH-000002 and so on.

Numbering across several files

Numbering continues across files. If the first file has 30 pages and numbering starts at 1, the second begins at 000031, following the order of the file list, which you can rearrange by dragging. There is no option to restart the count per file; process the files separately if you need that.

Digits, position and font

Padding can be 3, 4, 5 or 6 digits, or off. The count itself is not capped. Choose one of six spots, header or footer at the left, center or right, in Helvetica, Times New Roman or Courier. The margin scales with the page, and existing content is not moved, so on pages printed edge to edge the stamp can overlap it.

Real text, not an image

The numbers are real text, so they can be selected, searched and read by review software without OCR. They use the built-in PDF fonts, which cover Latin characters only, so a template with other scripts will fail.

How it works

A PDF library in your browser draws the stamp on each page and saves the numbered files to your downloads. The documents, the case name and the numbering are never sent anywhere.

What people use it for, and when it will not work

Litigation discovery, regulatory productions, audits, FOIA and records responses, due diligence rooms, any set where each page needs a unique number.

  • Redact before you stamp so the numbers sit on the final pages: Redact PDF.
  • For plain numbers without a prefix use Page Numbers.

Questions and answers

What is Bates numbering?
A way to give every page in a set of documents a unique sequential number, often with a prefix, so each page can be cited exactly.
How do I add Bates numbers to a PDF?
Add the file, choose a style or write a template, set the padding and position and press Apply Bates Numbers.
Is Bates numbering free here?
Yes, with no account and no limit on files.
Can I use my own prefix or case number?
Yes. Choose Custom style and write a template such as SMITH-[BATES].
Does the numbering continue across several PDFs?
Yes. The count follows the order of the file list and continues from one file to the next.
How many digits can the number have?
Zero padding can be 3, 4, 5 or 6 digits, or none. The count is not capped.
Are the Bates numbers searchable?
Yes. They are real text drawn in Helvetica, Times New Roman or Courier.
Are my documents uploaded?
No. The stamping happens in your browser and nothing is sent to a server.
