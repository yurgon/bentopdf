How to convert CSV to PDF

  1. Add your CSV files

    One or many. They stay on your device.

  2. Press Convert to PDF

    Each file becomes a table on landscape A4 pages.

  3. Save the PDFs

    One file downloads as a PDF; several come as a ZIP.

A CSV file is plain data with commas, easy for programs and hard for people. Converting CSV to PDF turns it into a readable table you can print, email or attach. The file is converted in your browser, so your data is never uploaded.

How the table looks

The first row becomes a bold header with a blue background and the rest become striped rows in 9 point text on landscape A4 pages. Long tables continue over as many pages as needed, with the header repeated on each page.

Commas, semicolons and tabs

The delimiter is detected automatically, so comma, semicolon, tab and pipe separated files all convert. Quoted fields with commas or line breaks follow standard CSV rules.

Wide files and other scripts

All columns are shrunk to the page width and cell text wraps, so very wide files get narrow columns. There is no page size or orientation setting; split wide data or drop columns you do not need. The file is read as UTF-8 and the PDF uses Helvetica, so accents work, but Chinese, Arabic or Cyrillic text may not display.

CSV to PDF or Excel to PDF

CSV holds raw values only, so no formatting is kept. For .xlsx or .xls files with formatting and several sheets use Excel to PDF. Rows that are completely blank are dropped, and a file with no values triggers an empty-file message.

How it works

A PDF library in your browser reads the CSV, draws the table and saves the PDF on your device. Your spreadsheet data is never sent anywhere.

What people use it for, and when it will not work

Data exports, inventory and price lists, survey results, logs, reports from databases and web apps.

  • Several CSV files come back as csv-converted.zip with one PDF each.
  • Check encoding. Files saved in other encodings can show garbled characters.

Questions and answers

How do I convert CSV to PDF?
Add the CSV file, press Convert to PDF and save the result.
Is CSV to PDF free?
Yes, with no account, no watermark and no limit on files.
How is the CSV laid out in the PDF?
A bold header row, striped rows in 9 point text and landscape A4 pages, with the header repeated on each page.
Does it work with semicolons or tabs?
Yes. The separator is detected automatically.
Why is my table squashed?
All columns shrink to fit the page width. Split wide data or remove columns.
Can I convert several CSV files at once?
Yes. One file gives a PDF; several are saved as a ZIP.
Does it handle accents and other alphabets?
Latin letters with accents work. Chinese, Arabic or Cyrillic text may not display.
Is my data uploaded?
No. The conversion runs in your browser and the file never leaves your device.
