How to add a watermark to a PDF

  1. Add your PDF

    One file. A preview of the page appears on your device.

  2. Design the watermark

    Type the text or choose an image, then set the size, color, opacity and angle. Drag it where you want it and choose Single or Tiled.

  3. Apply and save

    Choose the pages, then save. The watermarked PDF downloads.

What you get

A watermark is text or a logo laid over each page of a PDF, such as CONFIDENTIAL, DRAFT or your company name. It marks a document as yours or as not final. Here you design it on a live preview and save the result in your browser, so the file is never uploaded.

A diagonal CONFIDENTIAL or DRAFT mark

Stay in Text mode, type the word and raise the font size until it spans the page. The angle already defaults to -45 degrees for the classic diagonal look, so you usually only enlarge the text and drag it to the center of the preview.

A logo as the watermark

Switch to Image mode and upload a PNG or JPG; other formats are not accepted. A PNG with a transparent background blends best. Scale it from 10% to 200%, set its opacity and angle and drag it into place.

Single or tiled

Tiled repeats the watermark across the whole page in a diagonal grid that follows the angle. The horizontal and vertical gap sliders set the spacing as a percentage of the mark. Lower the opacity when tiling so the text underneath stays readable.

Some pages only, and tamper resistance

Type a range such as 1-3, 5, 7-9 in Page Range, or leave it on all. For a different mark on single pages, untick Apply to all pages and set each page with the arrows above the preview. A watermark is drawn into the page and can be removed by someone with an editor; Flatten watermark bakes it into page pixels, which is tamper-resistant but makes the text unselectable.

How it works

A PDF library in your browser draws the text or image onto the chosen pages and saves a new file. The preview, the logo and the document stay on your device.

What people use it for, and when it will not work

Drafts and contracts, confidential reports, invoices and quotes, photographers' proofs, exam papers, company documents that carry a logo.

  • Keep the original. A watermark is not undoable once the file is saved.
  • For a password as well, finish with Protect PDF.

Questions and answers

How do I add a watermark to a PDF?
Add the file, type text or choose an image, set the position and opacity, then save the PDF.
Can I watermark only some pages?
Yes. Type a range such as 1-3, 5, 7-9, or set each page separately.
How do I add a diagonal CONFIDENTIAL or DRAFT watermark?
Use Text mode, type the word and enlarge it. The angle defaults to -45 degrees.
Can I use my logo as a watermark?
Yes. Upload a PNG or JPG, then scale it, set the opacity and drag it into place.
What does Tiled do?
It repeats the watermark across the page in a diagonal grid, with gap sliders for the spacing.
Can someone remove the watermark afterwards?
It is drawn into the page and an editor could remove it. Flatten watermark makes it tamper-resistant but the text is no longer selectable.
Is adding a watermark free?
Yes, with no account and no limit on files.
Is my PDF uploaded?
No. The watermark is added in your browser and the file never leaves your device.
