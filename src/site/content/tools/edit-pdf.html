How to edit a PDF

  1. Open your PDF

    Drop the file onto the page or choose it. It opens right here in your browser, page by page.

  2. Click the text to change

    Click a paragraph and type. Delete words, fix a date or rewrite a line; the rest of the paragraph moves to fit.

  3. Add or replace

    Add a text box or an image, swap a logo, or use find and replace to change a word on every page.

  4. Export

    Press Export. The edited PDF is saved to your device and the editor stays open for more changes.

What you get

Most free PDF editors only let you draw boxes on top of a page. This one edits what is already written: the words in the file change, so the result is searchable, copyable and looks as if it was always that way. It runs entirely in your browser.

Change, delete or replace text

Click any paragraph and a cursor appears where you clicked. Type to add, select and delete to remove, or select a word and type over it. Lines reflow inside the paragraph, so a longer sentence wraps onto the next line instead of running off the page. Use the format panel for font, size, colour, bold, italic, underline, alignment and lists. Undo and redo work as in any text editor.

Delete a whole block by selecting it and pressing Delete. The words are removed from the file itself, not hidden under a white box, so they cannot be copied out or found by search later.

Add text boxes and images

Add a text box anywhere on a page for a note, a missing line or an answer on a form that has no fields. Add an image such as a logo or a stamp, or click an existing picture to replace it while keeping its place and size. Images can be rotated, flipped, aligned and put in front of or behind other content.

Find and replace across the document

Changed a company name, a price or a year? Find and replace goes through every page and swaps each match in the real text, one by one or all at once. A spell check for the current page catches typos before you send the file.

Fonts: why new letters sometimes look different

To save space, PDFs usually carry only the letters they use. If you type a letter the original font does not include, the editor has to borrow it from another font, and it may look slightly different. Check edited lines at full zoom. In Chrome and Edge you can also pick any font installed on your computer from the format panel.

How it works

The editor reads the page's drawing instructions, groups the letters into lines and paragraphs and shows them as editable text. When you export, it writes your changes back into those same instructions, so the rest of the page stays exactly as it was. The PDF is opened in memory on your device and never sent to a server.

What people use it for, and when it will not work

Fixing a typo in a CV or a contract before sending it, updating dates and prices on invoices and menus, changing names on certificates, filling in a form that has no fields, swapping a logo.

  • Scanned PDFs are pictures of text, so there is nothing to edit. Run OCR first to turn the scan into real text.
  • Signed documents lose a digital signature as soon as anything changes. That is by design: it is how signatures show tampering.
  • Complex layouts such as text on curves, very tight tables or text drawn as shapes may not be editable as paragraphs.
  • Comments and highlights are a different job; use Annotate PDF for those.

Edit a PDF on Mac, Windows, iPhone and Android

It works in any modern browser, so there is nothing to install and no Acrobat licence needed. On a computer you get the full toolbar. On a phone you can fix short texts, but a larger screen makes paragraph editing much easier.

Questions and answers

How do I edit a PDF for free?
Open the file on this page, click the text you want to change and type. Press Export to save the edited PDF. There is no account, no trial and no watermark.
Can I delete text from a PDF?
Yes. Click into the paragraph, select the words and press Delete; the remaining text closes up. The words are removed from the file, not just covered.
How do I edit a PDF without Acrobat?
Use this editor in your browser. It changes the text itself, like Acrobat does, and works on Mac, Windows and Linux without installing anything.
Can I edit a scanned PDF?
Not directly, because a scan is a picture. Run OCR first to turn it into text, then open the result here.
Will the new text match the original font?
Usually yes. If you type a letter the embedded font does not contain, it is taken from a similar font and may look slightly different, so check the line before you export.
Is my PDF uploaded to a server?
No. The file is opened and edited in your browser and saved back to your device. Nothing is sent anywhere.
How do I type or add text on a PDF?
Choose Add a text box, click where it should go and type. You can set the font, size and colour and move the box afterwards.
What is the difference between editing and annotating?
Editing changes the document itself. Annotating adds comments, highlights and drawings on top, which readers can see and remove. For those, use Annotate PDF.
