How to convert Markdown to PDF

  1. Paste or open your Markdown

    Type in the editor, paste text, or open a .md file. The preview updates as you type.

  2. Check the preview

    Headings, tables, code, math and diagrams appear as they will in the PDF.

  3. Save as PDF

    Press Export: your browser's print window opens. Choose Save as PDF as the destination and save.

Markdown is plain text with a few symbols for headings, lists and tables, used for READMEs, notes and AI answers. Converting Markdown to PDF gives a formatted document anyone can read. Here you write or paste it, see the result as you type, and save it, all in your browser.

Paste text or open a .md file

Paste from anywhere, such as a chat answer, a GitHub README or a note, or open a .md, .markdown or .txt file from your device. Edit in the left pane and watch the preview on the right; turn on sync scroll to keep both at the same place in long documents.

Tables, code, math and diagrams

The default mode follows GitHub-style Markdown: tables, task lists, strikethrough, footnotes and fenced code with syntax highlighting. Formulas between dollar signs are typeset with KaTeX, and code blocks marked mermaid become flowcharts, sequence diagrams and other charts. For strict CommonMark or bare Markdown, switch the preset.

Save as PDF

Export uses your browser's own print engine, the same one that prints web pages, so text stays sharp and selectable. In the print window, choose Save as PDF (in Chrome and Edge) or PDF in the lower left (in Safari on a Mac), pick the paper size and save. Only the rendered document is printed, not the editor.

How it works

Your Markdown is turned into formatted text by markdown-it with plugins for tables, footnotes, math (KaTeX) and diagrams (Mermaid), running in your browser. The preview is a normal web page, and the PDF is made by printing that page with your browser's print to PDF. Nothing you type is sent anywhere.

What people use it for, and when it will not work

READMEs and documentation, meeting notes, homework and lab reports, answers from AI chats, notes from Obsidian or other Markdown editors, and quick formatted documents without a word processor.

  • Saving goes through the print window; on a phone, use Share or Print, then save as PDF.
  • Images must be links to pictures on the web; files on your computer referenced by a relative path are not shown.
  • Page breaks are chosen by the browser; very long tables or code blocks continue on the next page.
