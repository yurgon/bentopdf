How to convert PDF to SVG

  1. Add your PDFs

    One file or several. They stay on your device.

  2. Press Convert to SVG

    Every page of every file is converted at its own page size.

  3. Save the SVG files

    One page saves as a .svg file; several pages come as a ZIP.

What you get

What each part becomes in the SVG
In the PDF In the SVG Note
Shapes and lines Vector paths Editable in a vector editor
Text Outlines (shapes) Not selectable, no font needed
Photos and scans Embedded raster images Makes the file larger
Pages One SVG per page SVG has no pages

SVG is a vector graphics format: shapes and lines described by math, so they stay sharp when you zoom or print large. Converting PDF to SVG is the way to reuse a logo, diagram or map from a PDF in a design tool or on a website. The conversion runs in your browser, so your file is not uploaded.

One SVG per page

SVG has no concept of pages, so every page becomes its own file. A single page downloads as filename.svg, a longer PDF as filename_svg.zip with page_1.svg, page_2.svg and so on, and several PDFs together as pdf_to_svg.zip.

Edit in Inkscape, Illustrator or Figma

The output is standard SVG. Shapes and paths arrive as editable vector objects, and the file opens in Inkscape, Illustrator, Figma and any web browser. Photos in the PDF stay raster images inside the SVG.

Text becomes outlines

Text is drawn as vector outlines, so it scales cleanly and does not depend on installed fonts, but it is no longer live text you can select or search. If you need the words, use PDF to Text as well.

When the SVG is large or unsuitable

Scanned or photo-heavy pages make big SVG files, because every image is embedded in the file. For image pages, PDF to PNG is smaller and more practical. There is no page range here; to convert only some pages, extract them first with Extract Pages.

How it works

A PDF engine (PyMuPDF compiled for the browser) writes each page as an SVG on your device. The first conversion downloads the engine, about 39 MB, once. A password-protected PDF asks for its password first. Your files are never uploaded.

What people use it for, and when it will not work

Logos and icons, diagrams and charts, maps, floor plans and technical drawings you want to reuse, scale or restyle.

  • Best for vector PDFs. A scan converted to SVG is just a picture inside an SVG wrapper.
  • No scaling or page range options. Pages keep their native size.

Questions and answers

How do I convert PDF to SVG?
Add the PDF, press Convert to SVG and save the file or ZIP.
Is PDF to SVG free?
Yes, with no account, no watermark and no limit on files.
Do I get one SVG or one per page?
One per page. A multi-page PDF is saved as a ZIP of SVG files.
Is the text in the SVG selectable?
No. Text is drawn as outlines, so it is sharp but not selectable. PDF to Text gives the words.
Can I edit the SVG in Illustrator or Inkscape?
Yes. It is standard SVG with editable paths and shapes.
Why is my SVG so large?
Scans and photos are embedded as images, which makes the file big. PDF to PNG is smaller for those pages.
Can I convert only some pages?
Not directly. Extract the pages first with Extract Pages.
Is my PDF uploaded?
No. The conversion runs in your browser and the file never leaves your device.
