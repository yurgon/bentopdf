How to unlock a PDF

  1. Add the locked PDF

    One file or several. They stay on your device.

  2. Enter the password

    Type the password the file asks for. If it opens without one but blocks printing or copying, leave the field empty.

  3. Unlock and save

    The PDF is saved without the password and restrictions; several files come as a ZIP.

What you get

Two kinds of PDF password
Kind What you see Can it be removed here?
Open password The file will not open until you type it Yes, if you know it
Permissions password Opens freely, but printing, copying or editing is blocked Yes, without a password
Forgotten open password The file will not open and nobody knows the password No, and no honest tool can promise it

To unlock a PDF is to take its password protection off, so it opens without typing anything and can be printed, copied and edited. Banks, payroll and government portals often send locked PDFs. This tool unlocks them in your browser, so the document is never uploaded.

Remove a password you know

Type the password once and the saved copy will open without it. This is useful for statements, payslips and tax forms you keep in your own archive, or need to merge, compress or upload somewhere that refuses locked files. Several files with the same password can be unlocked together.

Remove print and copy restrictions

Some PDFs open freely but will not let you print, copy text or fill in fields. That is a permissions password, and it can be lifted without knowing it: leave the password field empty. To only lift these limits, there is also Remove Restrictions.

What unlocking cannot do

If a PDF will not open and the password is lost, it cannot be unlocked here. The content is encrypted with that password, and guessing it is not something this tool does. Ask the sender for the password or a new copy. Please unlock only files you are allowed to open.

How it works

The file is decrypted in your browser with the password you typed, by a PDF engine running on your device, and saved as a normal PDF without encryption. Pages, text, images, links and form fields are copied as they are. The password and the document never leave your device.

What people use it for, and when it will not work

Bank and card statements, payslips, tax documents, school reports and e-tickets that arrive locked, before you print, merge, archive or upload them.

  • An unlocked copy has no protection. To send it on, add a new password with Protect PDF.
  • Forgotten open passwords cannot be removed.
  • Digitally signed PDFs lose the signature when they are unlocked, because the file changes.

Questions and answers

How do I remove a password from a PDF?
Add the file, type its password and press Decrypt PDF. The saved copy opens without a password.
Can I remove a PDF password for free?
Yes, with no account and no limit on files.
Do I need the password to unlock a PDF?
Only if the file asks for one when it opens. If it opens freely but blocks printing or copying, leave the field empty.
Can I unlock a read-only PDF?
Yes. A PDF that opens but cannot be printed, copied or edited unlocks without a password.
Can you unlock a PDF if I forgot the password?
No. Without the open password the content stays encrypted. Ask the sender for the password or a new copy.
Is it safe to unlock a PDF online?
Here the file and the password stay in your browser and are never uploaded, so it is as private as doing it on your own computer.
How do I put a password back?
Use Protect PDF to add a new password to the unlocked copy.
