How to convert a PDF to PDF/A

  1. Add your PDFs

    One file or several. They stay on your device.

  2. Choose the PDF/A level

    PDF/A-2b suits most archives. Pick 1b or 3b only if the recipient asks for it.

  3. Convert and save

    Press Convert to PDF/A. One file downloads directly; several come as a ZIP.

What you get

Which PDF/A level to choose
Level Best for Note
PDF/A-1b A recipient that demands it Strictest: no transparency, no layers
PDF/A-2b Most archives (default) Allows transparency and JPEG 2000
PDF/A-3b E-invoices and records with data files Allows embedded files such as XML

PDF/A is a version of PDF made for long-term storage. It embeds every font and fixes the color profile, so the document looks the same decades from now on any computer. Courts, tax offices, universities and archives often ask for it. This page converts your PDF to PDF/A in the browser, so confidential records are not uploaded.

Choose PDF/A-1b, 2b or 3b

The letter after the number is the conformance level. 2b is the default and fits most needs. 1b is the oldest and strictest and forbids transparency, so use it only when a recipient names it. 3b lets the file carry attachments, such as the XML data used by electronic invoices.

What the conversion changes

Every font is embedded as a subset, colors are converted to a standard sRGB profile, and features the chosen level forbids are dropped instead of stopping the whole job. Pages and text stay as they are, and the text remains selectable. The file is usually a little larger, because the fonts and the color profile are now stored inside it.

When a file will not convert

If a file with unusual fonts or transparency fails, turn on Pre-flatten PDF. It draws each page as an image at 300 DPI first, which gets around broken fonts, but the text is then no longer selectable, so try without it first.

Check the result if a rule requires proof

The conversion produces conforming files for the great majority of documents, but it is not a validator. If an authority, court or archive requires proof of compliance, check the saved file with a dedicated PDF/A validator such as veraPDF.

How it works

A Ghostscript engine compiled for the browser rewrites the PDF to meet the chosen PDF/A standard. Pre-flatten uses a second module that loads the first time it is needed. Everything runs on your device; the files are never sent to a server.

What people use it for, and when it will not work

Legal and court filings, tax records, contracts and invoices kept for years, theses and journal submissions, library and government archives.

  • Keep the original. PDF/A drops features such as layers and some transparency.
  • Size can grow. Run the result through Compress PDF, then validate again if strict compliance matters.
  • Scans need OCR first if you want them searchable: PDF OCR.

Questions and answers

How do I convert a PDF to PDF/A?
Add the file, choose a PDF/A level (2b by default), press Convert to PDF/A and save the result.
What is PDF/A?
A PDF standard for long-term archiving. It embeds all fonts and a color profile so the file looks the same in the future.
Which PDF/A version should I choose?
PDF/A-2b for most uses, 1b only if a recipient requires it, and 3b when the file must carry attachments such as XML data.
Is PDF to PDF/A free?
Yes, with no account, no watermark and no limit on files.
Can I convert several PDFs to PDF/A at once?
Yes. They are converted one after another with the same settings and saved together as a ZIP.
Why is the PDF/A file bigger?
PDF/A stores every font and a color profile inside the file. Compress PDF can shrink it afterwards.
Is the result guaranteed to pass a validator?
Not guaranteed. It works for most files, but if proof is required, check the file with a validator such as veraPDF.
Are my documents uploaded?
No. The conversion runs in your browser and the files never leave your device.
