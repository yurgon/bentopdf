How to make name tracing worksheets

  1. Type the name

    One name for a single sheet, or a list of names, one per line, for a sheet per child.

  2. Pick the letters

    Print or cursive, dashed or dotted, small, medium or large.

  3. Set the rows

    Choose how many rows to trace and how many empty rows for writing without help.

  4. Print

    Print straight away or save a PDF. Teachers get one file with every child’s sheet.

What you get

Name tracing worksheets help a child learn to write their own name: they follow dashed or dotted letters, see where each stroke starts and which way it goes, then try alone on the empty lines below. Make one sheet or a sheet for every child in a class. The names stay on your device.

Dotted or dashed letters, with start dots and arrows

Every letter is drawn as the path of a pen, not as an outline, so there is one clear line to follow. Dashed lines are easier for beginners to see; dots are finer and suit children who already hold the pencil well. On the first row each stroke has a green start dot, a number when the letter takes more than one stroke, and an orange arrow showing the direction: top to bottom, left to right, round letters such as a, c, d, g, o and q counterclockwise.

Print and cursive letters

Print letters are simple upright shapes for preschool and kindergarten. Cursive letters join up as in joined handwriting; they suit children from about second or third grade who are moving from print to cursive. Both sit on school ruling: a top line, a dashed middle line and a base line, with room below for letters such as g, j, p and y.

Worksheets for a whole class from a list of names

Paste the class list into the name box, one name per line, and you get one PDF with a sheet for each child in the same order, ready to print in one go. Up to 200 names fit in one file. A long name is made smaller so that it fits on a line, and the summary above the preview tells you when that happened.

Lines for independent writing

Below the tracing rows come empty rows with the same ruling, where the child writes the name without a model. Start with more tracing rows; as the letters become familiar, print sheets with fewer tracing rows and more empty ones. The name and date line at the top lets the child practice once more on every sheet.

Tips: how to practice writing a name

  • Short, frequent sessions work better than long ones: one sheet a day is plenty.
  • Start with the first letter in capital form and the rest in lowercase, the way the name is written at school.
  • Use a thick pencil or crayon and the large letter size for the youngest children.
  • Say the stroke out loud while tracing: “down, up and over”.
  • Praise the attempt, not neatness. Letters straighten out with practice.

How it works

The letters come from the Hershey single-stroke fonts, drawings of letters as pen paths made in the 1960s and free to use. For print letters the page puts the strokes in the order children are taught and draws start dots and arrows from the real path of each stroke. Everything is drawn in your browser; names are never sent anywhere.

What people use it for, and when it will not work

Preschool and kindergarten classes, homeschooling, speech and occupational therapy, name labels practice before school starts, practice for a new language’s alphabet.

  • Latin letters only. Accented letters such as é, ñ and ü work; Cyrillic, Greek, Arabic and Asian scripts do not yet.
  • Letter shapes follow one common model. Some schools teach slightly different forms of letters such as k, y or cursive capitals.
  • Very long names are made smaller to fit one line, which can make them small for young children; split a double name onto two lines if needed.

Questions and answers

At what age should a child learn to write their name?
Many children trace their name around age 3 to 4 and write it alone between 4 and 5, often before other words. Every child is different; tracing sheets help when the interest is there.
Can I make worksheets for several children at once?
Yes. Type one name per line and you get one PDF with a separate sheet for every name, in the same order as your list.
Are the worksheets free to print?
Yes. Make and print as many as you like at home or in school, with no account and no watermark.
Should I start with uppercase or lowercase letters?
Most teachers start with a capital first letter followed by lowercase letters, the way a name is written. Type the name exactly as you want it traced.
Can I make cursive name tracing worksheets?
Yes. Choose Cursive under Letters. The letters join as in handwriting, with a start dot and arrow on each letter of the first row.
What paper size is it?
A4 or Letter, chosen in the Paper option. Print at Actual size or 100% so the letters keep the size you chose.
How often should my child practice?
A few minutes a day is better than one long session a week. One sheet a day for a week or two is enough for most children to learn the shape of their name.
Are the names uploaded anywhere?
No. The sheets are drawn in your browser and saved to your device. Children’s names never leave it.
