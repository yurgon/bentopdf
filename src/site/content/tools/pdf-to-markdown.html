How to convert a PDF to Markdown

  1. Add your PDFs

    One or many. They stay on your device.

  2. Choose whether to include images

    Leave images off for a small, readable .md file. Tick the option for a self-contained file.

  3. Convert and save

    One file downloads as filename.md; several come as a ZIP.

What you get

How the PDF is read

Scanned pages Nothing Run PDF OCR first

Markdown is the plain-text format of notes, wikis, documentation and static sites. Converting a PDF to Markdown gives you headings, lists and emphasis you can paste straight into Obsidian, GitHub or a blog. The PDF is read in your browser, so the document is never uploaded.

How much structure is kept

Headings, paragraphs, lists and basic bold and italic come through, and each page is separated by a horizontal rule (---). Heading levels are inferred from font sizes, so a document with inconsistent styling may get some headings at the wrong level.

Images and file size

With Include images as base64 ticked, pictures are embedded in the Markdown so the single .md file is self-contained, but it can get large. Leave it off for text-heavy documents to keep the output small.

Scans and complex layouts

The converter reads the PDF's text layer, so a scanned document has nothing to convert; add a text layer with PDF OCR first. Multi-column text can be interleaved and footnotes or sidebars may land in the wrong place, so expect to tidy magazine-style pages. Single-column documents need little cleanup.

Markdown or plain text

PDF to Text gives raw text with no structure, better for scripts. PDF to Markdown keeps headings, lists and emphasis, so the result is ready for notes and documentation. A password-protected PDF asks for its password first.

How it works

A PDF engine (PyMuPDF compiled for the browser) reads the text and its font sizes and writes Markdown on your device. The first run downloads the engine, about 39 MB, once. Your PDF is never uploaded.

What people use it for, and when it will not work

Moving papers and manuals into Obsidian or Notion, preparing text for static sites and documentation, cleaning up reports for editing, feeding structured text to writing tools.

  • Check the headings. Levels come from font sizes and can be off.
  • Several PDFs come back as markdown-files.zip with one .md each.

Questions and answers

How do I convert PDF to Markdown?
Add the PDF, press Convert to Markdown and save the .md file.
Is PDF to Markdown free?
Yes, with no account, no watermark and no limit on files.
How well is the structure preserved?
Headings, paragraphs, lists and basic bold and italic are kept; heading levels come from font sizes.
What does Include images do?
It embeds pictures as base64 data, which makes one self-contained but larger .md file.
Why is the Markdown empty?
A scanned PDF has no text layer. Run PDF OCR first, then convert.
How does it handle columns and footnotes?
Complex layouts are the weak spot: columns can be interleaved and footnotes misplaced.
Is this the same as PDF to Text?
No. PDF to Text gives raw text; PDF to Markdown keeps headings, lists and emphasis.
Is my PDF uploaded?
No. The conversion runs in your browser and the file never leaves your device.
