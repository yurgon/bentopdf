How to crop a PDF

  1. Add your PDF

    One file. The first page opens as a preview on your device.

  2. Drag the crop box

    Move the corners or edges over the part to keep. Use the page arrows to set another box for another page, or tick Apply to all pages.

  3. Crop and save

    Press Crop & Download. The PDF is saved with every page trimmed.

What you get

Two ways to crop
Mode What happens Text selectable?
Default Sets the visible area; the rest stays hidden in the file Yes
Flattening Crop Pages become images; the trimmed area is gone No, and the file is usually larger

To crop a PDF is to cut away the margins or any part of a page you do not need, so the page shows only the content. It is handy for scans with black borders, slides with white edges and pages you want to paste into a document. This tool crops in your browser, so the file never leaves your device.

Drag a box over what to keep

The page appears as a preview with a movable box. Drag the corners or edges until it frames the part to keep. There is no field for exact measurements, so zoom the browser in when a margin is only a few millimeters wide.

Crop one page or every page

Use the page arrows to draw a separate box on each page; the tool remembers every box, and pages you never touch keep their size. To use one box everywhere, tick Apply to all pages and the box on the current page is copied to the rest.

Hide the margin or remove it

By default the tool sets each page's visible area. Viewers and printers show only the box, text stays selectable and quality is unchanged, but the trimmed part is still inside the file. Turn on Flattening Crop when it must be gone, for example before you share an excerpt. That turns each cropped page into an image, so the text is no longer selectable.

The page size after cropping

Each page takes the size of its box. Trimming a 1 inch margin from every side of a Letter page leaves a 6.5 by 9 inch page. To get back to a standard size, run the result through Fix Page Size.

How it works

The page preview is drawn by your browser. A PDF library on your device sets each page's crop area, or in flattening mode redraws the cropped part as an image, and saves a new file. The document is never uploaded.

What people use it for, and when it will not work

Scans with black or gray borders, slides and handouts with wide margins, figures and tables to reuse, pages to print without edges.

  • The default crop is not a redaction. Hidden content can be restored in a PDF editor. To hide private details for good, use Flattening Crop or Redact PDF.
  • File size stays about the same in the default mode, because the hidden margin is still in the file.

Questions and answers

How do I crop a PDF?
Add the file, drag the box over the part to keep, press Crop & Download and save.
Can I crop only some pages?
Yes. Move through the pages and draw a box on each one you want; pages you do not touch keep their size.
How do I crop every page the same way?
Tick Apply to all pages and the box on the current page is copied to every page.
Does cropping delete the part outside the box?
Not in the default mode: it is only hidden and can be restored. Flattening Crop removes it for good.
Will the text still be selectable?
In the default mode, yes. Flattening Crop turns pages into images, so text is no longer selectable.
Can I type exact crop measurements?
No. Crop by dragging the box; zoom the browser in for fine adjustments.
What size is the cropped page?
Each page takes the size of its box. Fix Page Size can bring it back to A4 or Letter.
Is cropping free and private?
Yes. It is free, needs no account, and the file never leaves your device.
