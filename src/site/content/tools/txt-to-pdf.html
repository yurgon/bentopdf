How to convert TXT to PDF

  1. Add a text file or type

    Upload one or more .txt files, or switch to Type Text and paste into the editor.

  2. Choose font, size and page

    Pick the font, size, color and page format. Margins are fixed at 1 inch.

  3. Create the PDF

    Press Create PDF. The file downloads as text_to_pdf.pdf.

A TXT file is plain text with no page, font or layout. Converting TXT to PDF turns it into pages that look the same on every device and print properly. You can upload text files or just paste text into an editor. Everything is created in your browser, so notes, logs and drafts are never uploaded.

Upload files or type text

Use Upload Files for one or more .txt files, or switch to Type Text, paste or type into the editor and press Create PDF. That is the quickest way to turn clipboard text into a PDF without saving a file first.

Fonts, sizes and page formats

Choose from Helvetica (sans-serif), Tiro and Times (serif) and Courier (monospace), at any size from 6 to 72 points, in any color. Page sizes cover the ISO A, B and C series from A0 to C10, plus US Letter, Legal, Tabloid and Ledger. Long lines wrap at the margin and line breaks from the text are kept.

Arabic, Hebrew and other right-to-left text

Right-to-left text is detected automatically: the direction switches and the text is right-aligned, in the editor and in the PDF.

Several text files

Several .txt files are joined into one PDF in list order, with a blank line between them and no page break. To give each file its own pages, convert them one at a time.

How it works

A PDF library in your browser lays the text out on pages with the font, size and margins you chose and saves the result on your device. The text you type or upload is never sent anywhere.

What people use it for, and when it will not work

Notes and drafts, server logs and code listings, text exports, lyrics and poems, anything copied from the clipboard that should become a document.

  • The file is always named text_to_pdf.pdf. Rename it after saving.
  • Need headings, bold or tables? Use Markdown to PDF or Word to PDF.
  • Margins cannot be changed. Pick a larger page size for more text per page.
