How to remove metadata from a PDF

  1. Add your PDF

    One file. It stays on your device.

  2. Check what will be removed

    The tool always clears the document info, the XMP data, the document IDs and private application data. There are no options.

  3. Remove and save

    Press Remove All Metadata. The cleaned PDF downloads.

What you get

What is removed and what stays
Part Result Note
Title, author, subject, keywords Removed Document properties
Creator, producer, dates Removed Created and modified times
XMP stream, document IDs, PieceInfo Removed Left by editors like InDesign
Comments and attachments Stay Use Sanitize PDF to strip them
EXIF inside images Stays Rasterize PDF re-renders pages

Every PDF carries hidden properties: who wrote it, which program made it and when it was created or changed. Before you publish or send a file, you may want those details gone. This tool clears them in your browser, so the file you are cleaning is never uploaded.

What metadata is removed

The document info fields (title, author, subject, keywords, creator, producer and the creation and modification dates), the XMP metadata stream, the document ID pair and the application-specific PieceInfo left by tools such as Illustrator or InDesign. There are no options; it always clears all of these.

What stays in the file

All visible content, plus form fields, annotations, bookmarks, links and file attachments. Names stored inside them, such as the author of a sticky note, are not touched. To strip comments, scripts and attachments too, use Sanitize PDF.

Metadata inside images

Image data is left as it is, so any EXIF or XMP information a photo carried when it was placed in the PDF stays with that image. If that matters, Rasterize PDF re-renders every page as a fresh image, at the cost of selectable text.

Check that it worked

Open the cleaned file in View Metadata and confirm the fields are blank. Running the same check on the original first shows exactly what is about to be removed. It cannot be undone, so keep your original.

How it works

A PDF library on your device overwrites the document info, deletes the XMP stream, the document IDs and private application data, and saves a new file. The file is never uploaded.

What people use it for, and when it will not work

Documents you publish or send to clients, files going to journalists or courts, CVs and reports where you do not want the author or software shown, anonymous reviews and tips.

  • The saving is small, usually a few kilobytes. For a real reduction follow up with Compress PDF.
  • Hidden or white text is part of the page and is not touched; review the document itself.

Questions and answers

How do I remove metadata from a PDF?
Add the file, press Remove All Metadata and save the cleaned copy.
What metadata does it remove?
Title, author, subject, keywords, creator, producer, dates, the XMP stream, document IDs and PieceInfo.
What stays in the file?
Visible content, form fields, annotations, bookmarks, links and attachments.
Does it remove metadata from images inside the PDF?
No. Image data is untouched. Rasterize PDF re-renders pages as new images.
How can I confirm the metadata is gone?
Open the cleaned file in View Metadata and check that the fields are blank.
Can this be undone?
No. The cleaned file keeps no record of the removed values, so keep your original.
Does removing metadata reduce file size?
A little, usually a few kilobytes. Compress PDF shrinks the file further.
Is my PDF uploaded?
No. The metadata is removed in your browser and the file never leaves your device.
