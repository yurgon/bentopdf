В генераторе подписи 14 рукописных шрифтов, все с OFL-1.1 (лицензия есть в каждом пакете `@fontsource/*`). Kalam (`@fontsource/kalam`) остаётся в старом интерфейсе BentoPDF и в подписи PDF.js.

Прописи используют однолинейные шрифты Hershey: каждая буква задана путём пера, поэтому точки начала и стрелки берутся из настоящего направления штриха. Условие лицензии Hershey (распространять благодарности вместе с данными) выполнено: текст лежит в поле `notice` файла `hershey.json`, который попадает в сборку. Пунктирные «шрифты для обводки» с сайтов шрифтов почти всегда только для личного использования, их не берём; пунктир рисуем сами по штриху.

Пример книги для PDF в EPUB (`public/samples/plyleaf-sample-book.pdf`, рассказ «The Blue Door») написан нами, свёрстан в Chrome шрифтом Georgia (в PDF встроено подмножество, как при любой печати в PDF).

- При публикации сохранить файлы LICENSE и уведомления сторонних библиотек в сборке.
- Ссылку на исходный код (наш открытый репозиторий) поставить в подвал и на страницу «О сайте» — требование AGPL для сетевых сервисов.
