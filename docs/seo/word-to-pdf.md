Страна: США. Данные: seodata.dev (показы в месяц, цена клика в долларах, конкуренция в рекламе 0–1, совпадение выдачи из 20). Собрано 2026-11-16. Выдача Google проверена 16.11.2026.

**Главный запрос страницы:** «word to pdf» — 110 000 показов в месяц, клик $1.05.

Всего по теме 35 запросов: главный запрос — 1, раздел — 25, вопрос — 5, не используется — 4. Ещё 6 запросов сервис отдал как похожие, но они не по теме (в карту не включены).

Близкие формулировки ведут на одну выдачу, поэтому показы складывать нельзя.

## Как собрано

1. Главный запрос из ТЗ и его похожие запросы из seodata.dev (сервис даёт до 10 похожих с оценкой совпадения выдачи).
2. Около 40 вариантов с типичными уточнениями (бесплатно, онлайн, как сделать, для класса, на телефоне и т. п.) и вопросы из выдачи, затем похожие на них, и так далее, пока запросы оставались в теме. Фильтр темы: `(word\|docx?\|ms word\|microsoft word\|document).{0,20}(to\|into\|as\|2) ?pdf\|pdf.{0,10}from (word\|docx?)\|(save\|export\|convert) (a )?(word\|docx?)`.
3. Совпадение выдачи с главным запросом сервис даёт только для прямых соседей. Для остальных оно оценено через общих соседей (минимум из двух совпадений) — это приближение, отмечено «≈».
4. Решения проставлены по правилам ТЗ: совпадение 15+ — раздел или вопрос на этой странице; другая выдача и своя задача — отдельная страница; отдельный вопрос — статья; чужие бренды, услуги и другие темы — не используется. Затем список просмотрен вручную.
