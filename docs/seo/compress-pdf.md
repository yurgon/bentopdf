**Главный запрос страницы:** «compress pdf» — 110 000 показов в месяц, клик $1.2.

Всего по теме 75 запросов: главный запрос — 1, раздел — 50, вопрос — 14, статья — 5, не используется — 5. Ещё 3 запросов сервис отдал как похожие, но они не по теме (в карту не включены).

## Как собрано

1. Главный запрос из ТЗ и его похожие запросы из seodata.dev (сервис даёт до 10 похожих с оценкой совпадения выдачи).
2. Около 40 вариантов с типичными уточнениями (бесплатно, онлайн, как сделать, для класса, на телефоне и т. п.) и вопросы из выдачи, затем похожие на них, и так далее, пока запросы оставались в теме. Фильтр темы: `(compress\|reduce\|shrink\|smaller\|minimi[sz]e\|decrease\|optimi[sz]e\|resize\|lower\|make).{0,25}pdf\|pdf.{0,20}(compress\|reduc\|size\|smaller\|shrink\|optimi\|under \d\|to \d+ ?(kb\|mb))`.
3. Совпадение выдачи с главным запросом сервис даёт только для прямых соседей. Для остальных оно оценено через общих соседей (минимум из двух совпадений) — это приближение, отмечено «≈».
4. Решения проставлены по правилам ТЗ: совпадение 15+ — раздел или вопрос на этой странице; другая выдача и своя задача — отдельная страница; отдельный вопрос — статья; чужие бренды, услуги и другие темы — не используется. Затем список просмотрен вручную.
