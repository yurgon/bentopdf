## Как собрано

1. Главный запрос из ТЗ и его похожие запросы из seodata.dev (сервис даёт до 10 похожих с оценкой совпадения выдачи).
2. Около 40 вариантов с типичными уточнениями (бесплатно, онлайн, как сделать, для класса, на телефоне и т. п.) и вопросы из выдачи, затем похожие на них, и так далее, пока запросы оставались в теме. Фильтр темы: `markdown\|\bmd\b\|\.md\|readme\|obsidian\|typora`.
3. Совпадение выдачи с главным запросом сервис даёт только для прямых соседей. Для остальных оно оценено через общих соседей (минимум из двух совпадений) — это приближение, отмечено «≈».
4. Решения проставлены по правилам ТЗ: совпадение 15+ — раздел или вопрос на этой странице; другая выдача и своя задача — отдельная страница; отдельный вопрос — статья; чужие бренды, услуги и другие темы — не используется. Затем список просмотрен вручную.
