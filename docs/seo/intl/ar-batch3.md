Страна: sa. Без данных (нет арабских запросов вообще): unlock-pdf, compare-pdfs, flatten-pdf, heic-to-pdf, pdf-to-svg, redact-pdf, protect-pdf, pdf-to-pdfa, form-creator, pdf-to-excel и excel-to-pdf (только английские формы оказались крупными). Для них главными выбраны английские формы, которые реально ищут.

Заодно исправлен сдвиг переводов в form-filler (значения для пунктов списка и первых вопросов FAQ стояли на соседних местах).

Замечание: большие запросы соседних страниц (не этих 25): «تحويل الصور الى pdf» около 135000, «تحويل بي دي اف الى صورة» 14800, «تعديل ملف pdf مجانا» 1900. Это страницы jpg-to-pdf, pdf-to-jpg, edit-pdf.
