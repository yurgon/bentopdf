# Ключевые слова, китайский (упрощённый), пакет 3

Страна: sg (Сингапур, единственная с данными по упрощённому китайскому), доп. проверка my (Малайзия). Данных очень мало, объёмы малые. Поэтому в заголовках и h1 теперь слитная форма.
