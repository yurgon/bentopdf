# Запросы на других языках

Для каждой страницы сайта и каждого языка главный запрос взят из нескольких вариантов на языке страны (что люди реально набирают), затем от него собраны похожие запросы с совпадающей выдачей. Подробно по каждому языку: файлы рядом, `<язык>.md`.

Нет данных в сервисе (Google Ads не работает в этих странах): Россия, Беларусь, Иран, Китай. Русский оценён по Казахстану. Белорусский, персидский и упрощённый китайский остаются с переводом интерфейса без страниц для поиска. Каталанский отдельно не измерить: в Испании запросы на каталанском и испанском совпадают, поэтому тоже только интерфейс.
